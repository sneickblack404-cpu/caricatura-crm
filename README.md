# 🎨 X1 CRM · Sistema de Vendas de Caricaturas no WhatsApp

Sistema de CRM e gestão comercial desenvolvido especificamente para operações de venda de **caricaturas personalizadas no WhatsApp**, inspirado na interface do **X1 CRM**.

---

## ⚡ Como Iniciar o Sistema

### Duplo Clique no Windows:
1. Dê um duplo-clique no arquivo **`iniciar.bat`**.
2. O sistema abrirá automaticamente o navegador em `http://localhost:3001`.

## 🚀 Funcionalidades Principais

### 1. Sistema Totalmente Zerado
- O banco de dados inicia com **0 vendas** e **0 follow-ups**, pronto para o início da sua operação real!

### 2. Modo Claro / Modo Escuro
- Botão no rodapé do menu lateral para alternar instantaneamente entre **Modo Claro** e **Modo Escuro**.

### 3. Registro Rápido de Venda (`+ Registrar Venda`)
- **Valor da Venda (R$)**: Campo livre para digitar o valor.
- **Profissão do Cliente**:
  - `Caminhoneiro`
  - `Freteiro`
  - `Pedreiro`
  - `Outro` (com campo aberto para digitar qual a profissão).
- **Número do WhatsApp do Cliente**: Com link para abrir no Zap.
- **Forma de Pagamento**: *PIX, Cartão 1x, Parcelado, Boleto*.
- **Linha do WhatsApp Utilizada**.
- **Observação do Pedido** (opcional).
- **Comissão**: 20% automática para todos os atendentes.

### 4. Painel Exclusivo do CEO (Gustavo Henrick)
- **Faturamento Bruto**
- **Taxas de Cartão/Gateway**
- **Faturamento Líquido**
- **Comissões da Equipe (20%)**
- **LUCRO LÍQUIDO REAL NO BOLSO** (com margem percentual)
- **Botão "Copiar Fechamento p/ WhatsApp"** (para acertar o PIX com cada vendedor)
- **Top Profissões Vendidas** e **Desempenho por Linha de WhatsApp**
